## Problem

Most small businesses collect enquiries through a form that was set up once and
never revisited: every field required, no branching, and submissions landing in a
mailbox nobody has agreed to own. The result is either an enquiry that stalls or a
form long enough that people abandon it.

## Scope delivered

Building Jotform forms to the client's specification and organising the wider
forms setup — the layout, the fields, and the structure of what gets asked.

Delivered engagements include one project in the **$400–$600** range recorded in
the account history, alongside smaller single-form builds.

deliberately **not** claimed here. Where an engagement included one it belongs to
that client's own stack, and I am not going to describe a routing chain that is
